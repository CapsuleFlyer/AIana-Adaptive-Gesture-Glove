# notebooks

Jupyter notebooks for exploring data and trying ideas.

Planned notebooks:
1. `01_signspeak_explore.ipynb`: load the SignSpeak table, check columns, plot a few signs, class balance.
2. `02_baselines.ipynb`: kNN/SVM/Random Forest on SignSpeak, confusion matrix.
3. `03_our_data_explore.ipynb`: our own glove recordings: noise, drift, separability.
4. `04_fewshot_experiments.ipynb`: accuracy at 1/3/5 examples.

Notebooks are for exploring. Anything the final demo depends on lives as code under [`src/aiana/`](../src/aiana/).
