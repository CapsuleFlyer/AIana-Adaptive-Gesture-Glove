# docs/report

The final project report.

Required sections (from the course statement): problem statement, real-world justification, selected path, objectives, methodology, algorithm description, system architecture/workflow (pipeline diagram), hardware description, implementation details, testing, results, limitations, conclusion.

Writing rules for this project:
- Justify each algorithm against our specific use case, not with generic statements.
- State clearly which numbers come from our own glove and which come from the SignSpeak data.
- Say how many volunteers and recordings we really have.
- Cite prior work (see [`../references.md`](../references.md)) and say how we differ: personalization from few examples, speech into video calls, laptop control, a conflict checker, and testing on unseen users.
- Be honest about limits: healthy volunteers only, small dataset, no clinical claims.
