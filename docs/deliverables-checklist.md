## Rules to remember
- The AI/ML component must be clearly identifiable and justified for our specific use case
- Hardware-software integration must be demonstrated (sensors, microcontroller, communication)
- If we use a software interface, it must work and be clearly connected to the glove
- Every member must be able to explain the implementation
- External datasets, libraries and models are allowed if we understand, document and justify them
- Do not copy existing projects. Cite what we reference.
